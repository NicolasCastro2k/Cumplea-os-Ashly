# Regalo para mi amiga

## Probar en tu computador
    npm install
    npm run dev

## Personalizar
1. Pon tus fotos en `public/fotos/`.
2. Edita textos y mensajes en `src/cartas.js`.

## Publicar en Vercel
1. Sube la carpeta a un repositorio de GitHub.
2. En vercel.com: Add New → Project → elige el repositorio.
3. Vercel detecta Vite solo. Pulsa Deploy.
